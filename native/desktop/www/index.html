逐光 Coach OS Desktop Native Shell
目标平台 Windows / Linux / macOS Tauri 原生桌面壳，复用逐光服务中台。
Native Desktop Application

把逐光服务中台安装到桌面系统

这是 Windows、Linux、macOS 的 Tauri 桌面应用启动壳。它保留独立窗口、系统级打包、图标和后续通知/自动更新扩展能力。

进入逐光平台
Windows 面向机构和运营团队，可产出 exe/msi 安装包。
Linux 面向训练机构自部署终端，可产出 AppImage/deb/rpm。
macOS 面向教练管理和运营工作台，可产出 app/dmg。
