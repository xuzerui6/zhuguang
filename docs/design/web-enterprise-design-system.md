# 逐光网页端企业级设计系统

## 设计原则

- 服务优先：官网第一屏直接支持找教练，不使用虚假规模数据或产品系统术语。
- 信息可信：教练经历、核验结论、场馆、价格和可约时间必须在操作前清楚展示。
- 身份清晰：学员、教练、运营使用独立壳层和 URL，同一账号通过模式菜单切换。
- 克制动效：页面壳层保持稳定，内容区只使用 160–220ms 的位移与透明度过渡。

## 设计令牌

- 品牌绿：`#087A46`；强调绿：`#056238`；浅绿背景：`#EAF7F0`。
- 主文字：`#111815`；正文：`#35413B`；辅助文字：`#6F7B75`。
- 页面背景：`#F5F7F6`；分割线：`#DFE5E1`；白色表面：`#FFFFFF`。
- 状态色：蓝 `#2674D9`、琥珀 `#C67A13`、珊瑚 `#DC624D`。
- 内容最大宽度：`1280px`；桌面页边距不少于 `24px`；移动端页边距 `16px`。
- 常规圆角 `5–8px`；正文 `14–16px`；触控和主要交互区域不小于 `44px`。

## 页面与组件

- 官网使用真人训练主视觉、服务搜索条、审核教练、服务流程、保障、训练方案与教练合作。
- 学员平台使用顶部导航；找教练页采用筛选、结果列表和固定详情栏。
- 教练与运营平台使用分组侧栏；表格、时间表、会话和详情栏保持固定信息层级。
- 原生移动 App 只在 Capacitor 环境加载，浏览器端始终使用响应式网页组件。
